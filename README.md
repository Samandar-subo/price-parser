# Парсер каталога в Excel

Скрипт на Python собирает название, цену и ссылку товаров со страницы каталога и сохраняет их в отформатированный Excel-файл. Селекторы настраиваются из командной строки, поэтому под новый сайт ничего не нужно переписывать.

В папке `sample/` лежит учебная страница каталога, на ней можно проверить работу без интернета.

## Что умеет

- Достаёт товары по CSS-селекторам: карточка, название, цена, ссылка
- Приводит цены к числам: «12 500 ₸», «от 18 900 ₸», «9 750,50 ₸», «по запросу» (пустая ячейка)
- Пропускает рекламные блоки без названия товара
- Проходит по страницам через ссылку «Дальше», с паузой между запросами
- Проверяет `robots.txt` и останавливается, если сайт запрещает автоматический сбор
- Сохраняет Excel: заголовки, фильтр, закреплённая шапка, числовой формат цены

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# проверка на учебной странице
python catalog_parser.py --file sample/catalog.html --out catalog.xlsx

# настоящий сайт
python catalog_parser.py --url https://example.com/catalog \
    --item ".card" --name ".card-title" --price ".card-price" \
    --next "a.next" --max-pages 5 --out catalog.xlsx
```

Чтобы найти селекторы, откройте страницу в браузере, нажмите правой кнопкой на название товара и выберите «Просмотреть код».

## Тесты

```bash
pytest -q
```

## Важно

Парсер собирает только публичные данные и уважает `robots.txt`. Перед сбором данных с чужого сайта проверьте его правила использования. Сайты с защитой от ботов и динамической подгрузкой (JavaScript) требуют отдельного подхода.
